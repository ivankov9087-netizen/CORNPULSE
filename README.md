# CORNPULSE

Fields Foodの動画で紹介した、視聴者向けの無料オフラインFPSです。

ポータル、グラップル、ウォールランを使って飛び回り、
野菜の大群を倒しながら強化するゲームです。

A free offline FPS made for Fields Food viewers.

## ダウンロード / Download

**[最新版はこちら / Latest release](https://github.com/ivankov9087-netizen/CORNPULSE/releases/latest)**

リンク先の「Assets」から、Windows用のゲームZIPをダウンロードしてください。
「Source code」はゲーム本体ではありません。

Download the Windows game ZIP under “Assets”, not “Source code”.

## 起動方法 / How to play

ZIPをすべて展開し、フォルダー内の「CORNPULSE.exe」を起動してください。
EXEだけを移動せず、付属ファイルも一緒に置いてください。

Extract the entire ZIP, then run CORNPULSE.exe.
Keep all bundled files and folders together.

Windows 64-bit / Keyboard & mouse / Offline
ゲームパッドには対応していません。 / Gamepad not supported.

## TIPS

無料FPSですがRaw InputやFOVスライダー、キーバインドなど設定項目は充実しています。
おすすめはポータルを**マウスホイールの↑／↓**、グラップルを**Eキー**に割り当てることです。
ポータルの設置とグラップルの操作が、ぐっとスムーズになります。

CORNPULSE is a free game with plenty of settings, including Raw Input, an FOV slider, and customizable keybindings.
For smoother controls, try binding portals to mouse wheel up/down and the grapple to E. This makes placing portals and grappling much easier.
